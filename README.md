# AnyRouter 自动登录工具

一个功能强大的 AnyRouter 平台自动登录工具，支持批量账号管理、并发登录、余额查询等功能。

## ✨ 功能特点

- 🖥️ **图形化界面**：友好的GUI界面，操作简单直观
- 👥 **批量账号管理**：支持从文件导入多个账号，批量处理
- ⚡ **并发登录**：支持多线程并发登录，提高效率
- 💰 **余额查询**：自动获取并显示账户余额信息
- 🌐 **多浏览器支持**：自动检测并使用系统已安装的浏览器（Chrome、Edge、Firefox）
- 🎯 **灵活选择**：可勾选指定账号进行登录
- 📊 **实时日志**：实时显示执行进度和结果
- 🔄 **拖拽排序**：支持账号列表拖拽排序

## 📦 安装说明

### 1. 安装Python依赖

```bash
pip install playwright
```

### 2. 初始化Playwright（重要）

```bash
# 初始化playwright，这一步会安装必要的浏览器驱动
# 不会安装浏览器本体，只是安装驱动程序
playwright install
```

**说明**：
- 程序会自动检测并使用您电脑上已安装的浏览器（Chrome、Edge、Firefox）
- `playwright install` 只是安装驱动程序，用于控制您已有的浏览器
- 无需额外下载浏览器，使用您电脑上现有的即可

## 🚀 快速开始

### 1. 准备账号文件

创建 `accounts.txt` 文件，格式如下：

```text
# 账号配置文件
# 格式: 用户名,密码
# 每行一个账号，使用逗号分隔用户名和密码
# 以 # 开头的行为注释

user1@example.com,password1
user2@example.com,password2
```

### 2. 启动程序

#### 方式一：GUI界面（推荐）

```bash
# Windows用户可以直接双击运行
启动GUI.bat

# 或使用Python运行
python auto_gui.py
```

#### 方式二：命令行版本

```bash
# 串行执行（稳定）
python auto_optimized.py

# 并行执行（高效）
python auto_parallel.py
```

## 🎮 使用说明

### GUI界面操作

1. **启动程序**：运行程序后会自动检测您电脑上的浏览器
2. **导入账号**：点击"📁 导入"按钮，从 accounts.txt 导入账号
3. **选择浏览器**：在下拉框中选择要使用的浏览器（程序会显示检测到的浏览器）
4. **配置选项**：
   - 选择浏览器类型（自动检测到的）
   - 设置并发数量（1-5）
   - 选择是否无头模式（后台运行）
5. **开始执行**：点击"🚀 立即执行"开始自动登录
6. **查看结果**：在账号列表和日志窗口查看执行结果

### 功能按钮说明

- **📁 导入**：从 accounts.txt 文件导入账号
- **➕ 添加**：手动添加单个账号
- **✏️ 编辑**：编辑选中的账号信息
- **🗑️ 删除**：删除勾选的账号
- **☑ 全选**：选中所有账号
- **☒ 反选**：反选账号选择状态
- **☐ 清空**：取消所有选择
- **📊 刷新**：刷新账号状态
- **📄 日志**：查看详细日志文件

## 📁 文件说明

- `auto_gui.py` - GUI版本主程序
- `auto_optimized.py` - 命令行优化版本
- `auto_parallel.py` - 并行执行版本
- `启动GUI.bat` - Windows批处理启动器
- `accounts.txt` - 账号配置文件（需自行创建）
- `config.json` - 程序配置文件（自动生成）
- `login_log.txt` - 执行日志文件（自动生成）

## ⚙️ 配置说明

### 浏览器配置
- **自动检测**：程序启动时会自动检测已安装的浏览器
- **无头模式**：后台运行，不显示浏览器窗口
- **有头模式**：显示浏览器窗口，便于调试

### 并发配置
- **并发数量**：同时运行的浏览器数量（1-5）
- 建议根据电脑性能和网络状况调整

## 🔧 故障排除

### 常见问题

1. **提示"未检测到支持的浏览器"**
   - 确保电脑上已安装Chrome、Edge或Firefox中的至少一个
   - 运行 `playwright install` 安装浏览器驱动

2. **提示"playwright未安装"**
   ```bash
   pip install playwright
   playwright install
   ```

3. **登录失败**
   - 检查账号密码是否正确
   - 检查网络连接
   - 尝试减少并发数量

4. **余额获取失败**
   - 等待页面完全加载
   - 检查网站是否有更新

### macOS/Linux用户注意事项

由于`启动GUI.bat`是Windows批处理文件，macOS/Linux用户请直接使用Python运行：

```bash
python auto_gui.py
```

或创建启动脚本 `start.sh`：

```bash
#!/bin/bash
python auto_gui.py
```

然后执行：
```bash
chmod +x start.sh
./start.sh
```
